# Verificación

**Propósito:** sustentar cada entrega con comprobaciones proporcionales al cambio.

**Alcance:** código, configuración y documentación.

**Cuándo se aplica:** antes de declarar terminada una tarea y durante revisiones.

**Decisiones:** valida el comportamiento afectado y añade tests cuando exista lógica relevante. Para documentación, revisa enlaces, coherencia y privacidad; no crees tests que solo repitan el texto. Registra qué se ejecutó y su resultado. Distingue aprobado, no aplicable y pendiente. No declares completa una tarea si falla una comprobación requerida. No afirmes que la demo funciona cuando todavía no existe.
