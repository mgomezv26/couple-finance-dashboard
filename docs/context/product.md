# Producto

`couple-finance-dashboard` es un proyecto de dashboard financiero para parejas. Su propósito es facilitar una visión compartida de las finanzas mediante una aplicación comprensible y mantenible.

Está dirigido a parejas que quieran consultar sus propios datos y a quienes quieran explorar el proyecto con ejemplos ficticios. Alex y Sam son los únicos nombres de ejemplo establecidos; no representan usuarios reales.

Se han decidido dos fuentes futuras: demo sintética y Google Sheets propio del usuario ([ADR 0001](../adr/0001-demo-and-google-data-sources.md)). El flujo externo previsto comienza en Google Forms. No están definidos indicadores, pantallas, categorías, reglas de reparto ni otras funcionalidades financieras.

La fundación actual prepara el desarrollo con agentes. No entrega funcionalidades al usuario final; su alcance verificable está en la [spec 001](../../specs/001-project-foundation/spec.md).
