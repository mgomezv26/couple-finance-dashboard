# Python

**Propósito:** producir código legible y mantenible.

**Alcance:** futuros módulos Python y tests.

**Cuándo se aplica:** al crear, modificar o revisar Python.

**Decisiones:** usa nombres descriptivos, funciones pequeñas y type hints cuando aclaren contratos. Evita duplicación y abstracciones sin necesidad demostrada. Añade comentarios educativos sobre motivos y conceptos, no comentarios obvios línea por línea. Sigue las convenciones comprobadas en el código; aún no hay versiones ni herramientas de lint decididas.
